# Contracts

Interfaces between teammates (functions, JSON schemas, ports). Update and post on the board when they change.

- Glove stream: Rokoko Studio -> UDP 127.0.0.1:14043 (JSON v3). Parsed fingers: 5 floats 0..1 (TBD after seeing a real frame).
- Robot hand (`robot/hand.py`): `make_hand(kind, **kw)` -> `Hand.set_fingers([5 floats 0..1])`, 0=open, 1=closed, order thumb,index,middle,ring,pinky. kinds: `dry`, `sim` (MuJoCo), `serial` (Arduino, `port=`; line `a,b,c,d,e\n` ints 0-180 @115200), `pca9685` (channels 0-4).
- UDP driver: `python -m robot.run_udp --backend sim --port 14043` accepts `{"fingers":[5]}` JSON (mock_stream / forward_to_jetson format).
- Retargeting (`robot/retarget.py`): glove 5 floats (1=closed) -> Inspire RH56 6 ints 0..1000 [pinky,ring,middle,index,thumb_bend,thumb_rot], 1000=open. `make_hand("inspire", host=..., dry=False, close_cap=0.6)` (Modbus TCP, registers UNVERIFIED on hardware). CLI: `python -m robot.run_udp --backend inspire [--live --host IP --close-cap 0.6]`. `close_cap` = max closure, hook for fragile-grasp assist (#14).
- Two gloves (`Rokoko/src/rgmp_client.py`): single-hand stream unchanged on 14043 `{"fingers":[5],"t":..,"src":"rokoko","hand":"left|right"}` (choose with `--hand`). Bimanual: `--bimanual-port 14053` sends `{"left":[5]|null,"right":[5]|null,"t":epoch_s}`; a hand is null until that glove has been seen/calibrated. Finger order thumb,index,middle,ring,little; 0=open, 1=closed.
- Bimanual consumers (`robot/parse.py: parse_hands`): robot.run_udp and demo/dashboard accept both the single-hand and bimanual UDP formats. `python -m robot.run_udp --port 14053 --hand left|right` picks the glove for a robot hand; `demo/run_demo.sh --bimanual --hand left`. Dashboard shows left (magenta/dashed) and right (cyan) together.
- Grasp assist wired: `python -m robot.run_udp --assist cup|egg|can` (open-loop cap from ml/grasp_assist.py); `demo/run_demo.sh --assist egg`. Force feedback: pass `force=` to GraspAssist.apply once a sensor exists.
- **hand_state v1** (frozen, PLAN 1.2): one JSON object per hand per sample, shared by UDP, recorder and policy. Required: `t` (epoch s), `hand` ("left"|"right"), `fingers` ([5 floats 0..1], thumb,index,middle,ring,little, 0=open 1=closed). Optional, consumers ignore if absent: `joints` (per-joint floats, order documented by producer), `wrist_quat` ([x,y,z,w]), `button` (bool, e.g. hand-off/clutch). Unknown keys ignored; additions stay backward compatible within v1. Single-hand UDP packet is already a hand_state; the bimanual packet stays `{"left":[5]|null,"right":[5]|null,"t"}`.
- **hand_state v1.1** (additive, Coil Pro): optional `wrist_position` ([x,y,z], Coil Pro frame, units unverified, assumed metres), `wrist_quaternion` ([w,x,y,z]; supersedes v1 `wrist_quat` [x,y,z,w], both accepted), `button_pressed` (bool; Smartgloves II RGMP has no button, only STATUS_FLAGS, so it is currently never emitted). `rgmp_client.py` emits the wrist fields from group `default` TRANSFORM `arm_sensor` ref `coil_pro` (FLOAT[7] = pos + quat xyzw, layout assumed). v1 keys stay valid.
- Raw RGMP replay (`Rokoko/src/replay_rgmp.py`): `python Rokoko/src/replay_rgmp.py data/raw/x.rgmp [--port 12276 --speed 1 --loop]` serves a recorded stream like the real Rokoko server, so `rgmp_client.py` runs unchanged. Record: `python Rokoko/src/replay_rgmp.py --record out.rgmp [--host H --port P --seconds N]`.
- **Sim scene + truth test (PLAN 1.3/1.4, `robot/`)**: `robot.scene.Scene(obj="cube"|"egg")` (Inspire-style 5-finger hand, wrist = 3 slide joints, egg `broken` latched above BREAK_FORCE_N=3 N, toy-calibrated). `python -m robot.scene --obj egg --cap 0.5`. `robot.pipeline.Pipeline(obj, profile)` consumes hand_state packets (`fingers`, optional `wrist_position` [x,y,z] metres from Coil Pro, relative to first sample; else mock wrist path) and reports `latency_ms` (compute only) + p50/p95. `robot.parse.parse_state` accepts BOTH `wrist_quaternion` [w,x,y,z] and v1 `wrist_quat` [x,y,z,w], and `button_pressed` or `button`. `pytest tests/test_truth.py` runs in GitHub Actions (`.github/workflows/truth.yml`).
- **G1 Dex3 retargeting (`robot/g1_dex3.py`)**: `G1Dex3Retargeter().step(left=[5]|None, right=[5]|None)` -> 14-value hand_q (left 7 then right 7, order from docs/g1_dex3_limits.json), clamped to FILTER bounds, slew-limited 0.1 rad/tick @30 Hz. index/middle -> 2 joints each, ring/little ignored, left closes negative / right positive. THUMB = interim pinch coupled to index (UNVERIFIED direction). Backend `make_hand("g1dex3", hand="left|right")` (dry, `last_q`, no DDS). Tested on all 43 episodes: 0 out-of-bounds.
